## 🚀 Projetos

### [Treinanda](https://treinanda.com.br)
Plataforma web de treino para o ENEM, lançada em versão beta, criada e mantida por mim.
- Banco com mais de 2.500 questões, montado a partir de uma API pública do ENEM e processado com IA (Groq)
- **Stack:** Java, Spring Boot, IA (Groq)

### [Cashen](https://cashen.com.br)
Gestão financeira para motoristas de aplicativo, desenvolvida em equipe de 5 pessoas e em validação com motoristas.
- Web e app Android para controlar ganhos por corrida, despesas do veículo, contas recorrentes e metas, com resumo mensal do lucro real
- Autenticação com JWT, 2FA e Google OAuth
- **Stack:** Node.js, Express, Prisma, PostgreSQL, Next.js, React Native (Expo)

### [Organiza-aí](https://github.com/pauloosmt/Organiza-ai)
Aplicação web para estudantes universitários controlarem faltas por disciplina, com alertas antes de ultrapassar o limite permitido.
- Identificação automática de conflitos de horários e suporte a múltiplos usuários com dados isolados
- Publicado em produção
- **Stack:** Java 21, Spring Boot, Angular, Gradle

### [ZettaFire](https://github.com/pauloosmt/zettaFire)
Monitoramento em tempo real de focos de incêndio em Minas Gerais.
- Pipeline em Python para ingestão automatizada de dados
- Cálculo geoespacial com PostGIS para associar focos a usuários em raio de risco
- **Stack:** Python, PostgreSQL, PostGIS, React Native (Expo)
